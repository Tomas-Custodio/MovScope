# Movsope

O **Movsope** é um projeto de desenvolvimento web, sem fins comerciais, dedicado à descoberta e consulta de filmes e séries.

Permite aos utilizadores explorar conteúdos cinematográficos através de filtros por género, ano de lançamento, popularidade e avaliação.

A plataforma disponibiliza informações sobre cada produção, incluindo sinopses, classificações, elenco, trailers e outros detalhes relevantes, proporcionando uma experiência simples e intuitiva para os amantes de cinema e entretenimento.

O Movsope não inclui sistema de registo, autenticação ou contas de utilizador, uma vez que o seu propósito é exclusivamente informativo e de consulta.

O seu objetivo é facilitar a descoberta de novos filmes e séries, reunindo informações cinematográficas numa única plataforma.
