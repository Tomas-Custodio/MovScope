# 🎬 MovScope

O **MovScope** é um projeto de desenvolvimento web, sem fins comerciais, dedicado à descoberta e consulta de filmes e séries.

O seu objetivo é facilitar a descoberta de novos filmes e séries, reunindo informações cinematográficas numa única plataforma, de forma simples e intuitiva.

---

## ✨ Funcionalidades

- 🔎 **Filtros** por género, ano de lançamento, popularidade e avaliação
- 📝 **Sinopses** de cada produção
- ⭐ **Classificações** e avaliações
- 👥 **Elenco**
- 🎞️ **Trailers**
- 📋 Outros detalhes relevantes de cada filme e série

## ℹ️ Nota

O MovScope **não inclui sistema de registo, autenticação ou contas de utilizador**. O seu propósito é exclusivamente informativo e de consulta.
